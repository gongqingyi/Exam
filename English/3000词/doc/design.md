# 词汇四选一练习

按「天」做选择题测评：先选大类与天，再选方向（`英 → 中` 或 `中 → 英`），一次只出一词。每题 ABCD 四选一；正确答案随机落在其中一格，另外三格由 AI 生成易混淆干扰项（不得与正确答案同义到可选对）。只判对 / 错。同一场方向锁定；做完或中途退出后写汇总报告（Markdown），并进入历史索引。

应用在 `English/3000词/web`。词表直接读各大类批次下的 `默写/words.json`，不另抄一份。产品说明本文档在 `English/3000词/doc/design.md`。

## 练习方式

1. **首页**：开始测评 / 历史测评 / 历史统计。
2. **测评导航**：大类 Tab（高频常用、重点必背、拓展补充）+ 方向 Tab；下方 15 天网格（词数）。选天后点「开始测评」。
3. **会话锁定**：一场只允许一个方向；开始后不可切换。换方向须提前退出后重开。
4. **出题加速**：开始时先同步生成前 5 题选项即可进入作答；其余题目在后台按批继续生成。翻到尚未就绪的题时显示「正在生成选项…」，并轮询 `/api/choices`。
5. **一次一词**：只显示当前 prompt；词序与默写条一致，跳过 `type: sec`（`sec` 仅作类别）。作答后显示参考答案、用户选择、对错与响应时间。
6. **翻题**：「上一个」「下一个」底栏居中，间距 20px。未作答点「下一个」须确认；确认后记为跳过（错）。回到已答旧题只读，报告以该题最后一次有效作答为准。
7. **结束**：最后一题作答后点「提交」完成；或「提前退出」。结束 / 中止时浮层提示「写报告中」，完成后进入汇总报告页。

## 计时与结果

浏览器上报进入本题时间与客户端耗时；权威字段以服务端会话 JSON 为准。

### 会话级

| 字段 | 说明 |
|---|---|
| 开始 / 结束时间 | 开始测评、完成或提前退出 |
| 方向 | `en_zh` / `zh_en` |
| 大类 / 批次 / 天 | 如 `高频常用` · `1.高频常用/1-5d` · 第 1 天 |
| 词条数量 | 本场详单条数（含跳过） |

### 词条级

| 字段 | 说明 |
|---|---|
| prompt / 正确答案 | 题目侧与标准答案 |
| 用户选择 | 所选选项文本；跳过为空 |
| 判别 | `correct` / `wrong` |
| 用户响应时间 | 进入本题 → 提交或跳过（毫秒） |

## 出题与判分

- DeepSeek（`config/key.yaml`）批量生成干扰项；失败时启发式回退。
- 客户端点选 A–D 即提交；服务端比对 `correct_key`，对 100 / 错 0。
- 无语音识别、无「相关」档。

## 汇总报告

结束后展示报告页，并写入：

```
English/3000词/web/reports/
  <高频常用|重点必背|拓展补充>/
    YYYY-MM-DD/
      day<N>_<en_zh|zh_en>_<HHmmss>.md
```

会话落盘：`web/data/sessions/<session_id>.json`；历史索引：`web/data/index.json`（原子写入：先 `.tmp` 再 `os.replace`）。

## 历史测评 / 历史统计

- 过滤顺序：**大类 → 方向 → 天**（与测评导航同款天网格），再下列表。
- 历史测评：当日该方向的各次报告摘要，可打开详单。
- 历史统计：从**已结束会话 JSON**聚合错词（评测次数、错误次数、错误率、最近评测时间）。原词条 / 正确答案单元格自动换行增高，不截断。

## 接口（要点）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/days` | 各大类批次与天、词数 |
| POST | `/api/session/start` | 建会话；返回题目列表 + 已就绪的前若干题 options；后台续生成 |
| GET | `/api/choices?session_id&index` | 取单题选项（未就绪则短时等待） |
| POST | `/api/attempt` | 提交选择或 `ended_reason=skipped` |
| POST | `/api/session/finish` | 汇总、写 Markdown、更新索引 |
| GET | `/api/history` | 历史列表 |
| GET | `/api/history/{id}` | 报告 JSON |
| GET | `/api/stats/errors?category&direction&day` | 错词统计 |

## 页面结构

单页：`首页` → `测评导航` → `测评中` → `汇总报告`；旁路 `历史测评` / `历史统计`。

### 测评中

- 顶栏：大类·天、方向、进度、「提前退出」
- 中部：题干、ABCD、结果表（作答后）
- 底栏：居中「上一个」「下一个」（间距 20px）；末题作答后显示「提交」
